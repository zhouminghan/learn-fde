# Multi-Agent 调优

## 本章目标

学完本章后，你应当能够：

- 识别角色边界与协同方式的问题。
- 控制通信成本与冲突处理。
- 设置清晰的终止条件与结果验证。

## 核心概念

- **角色边界**：每个 Agent 的职责与权限。
- **通信成本**：Agent 之间传递信息的开销。
- **冲突处理**：多 Agent 输出不一致时的裁决方式。

## 原理与机制

Multi-Agent 调优围绕角色边界、通信效率、冲突处理与终止条件展开。角色边界清晰可减少重复；通信协议简洁可降低成本；明确终止条件避免无限循环。

```mermaid
flowchart LR
  A[角色边界] --> B[协作协议]
  B --> C[执行与通信]
  C --> D[冲突处理]
  D --> E[终止与汇总]
```

## 企业场景

内容创作中，审校 Agent 与撰写 Agent 对同一段落意见不一致。通过设定“审校拥有最终裁决权”的规则，避免无限往返。

## 风险与常见误区

- **误区**：Agent 越多越好。
- **误区**：没有冲突裁决规则导致来回拉锯。
- **风险**：通信成本过高抵消并行收益。

## 验收标准

能够说明角色边界、通信成本、冲突处理与终止条件的调优要点。

## 本章小结

Multi-Agent 调优的核心是让协作更可控：清晰边界、简洁通信、明确裁决与终止条件。

## 自测题

1. 为什么角色边界要清晰？  
   **答**：减少职责重叠与重复劳动。
2. 冲突如何处理？  
   **答**：设定明确的裁决规则，如某角色拥有最终决定权。
3. 为什么 Agent 数量并非越多越好？  
   **答**：会增加通信成本与协调难度。
