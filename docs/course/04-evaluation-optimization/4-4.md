# Workflow 调优

## 本章目标

学完本章后，你应当能够：

- 识别工作流节点设计的问题。
- 优化流程效率与异常处理。
- 利用可观测性定位瓶颈。

## 核心概念

- **节点设计**：每个节点的输入、输出与职责。
- **条件路由**：根据结果路由到正确路径。
- **可观测性**：通过日志、状态与耗时观察运行过程。

## 原理与机制

Workflow 调优从可观测性入手：记录每个节点的状态与耗时，定位瓶颈、异常与错误节点，再优化节点设计、分支路由与异常处理。

```mermaid
flowchart LR
  A[运行与观测] --> B[定位瓶颈]
  B --> C[优化节点]
  C --> D[改进路由]
  D --> E[回归验证]
```

## 企业场景

一个审批工作流耗时过长。通过节点耗时分析发现模型节点是瓶颈，团队通过缩小上下文与增加缓存把整体耗时降下来。

## 风险与常见误区

- **误区**：只看最终结果，不关注中间节点。
- **误区**：异常路径缺失，失败后流程卡住。
- **风险**：盲目并行导致依赖顺序错误。

## 验收标准

能够利用节点状态与耗时定位瓶颈，并给出优化方案。

## 本章小结

Workflow 调优依赖可观测性。定位瓶颈、改进节点与路由、补齐异常路径是主要手段。

## 自测题

1. 可观测性在 Workflow 中的作用是什么？  
   **答**：定位瓶颈、异常与错误节点。
2. 为什么需要异常路径？  
   **答**：避免流程在失败后卡住，保证有兜底。
